# Garden Highway Community Association website

A maintainable React and Vite project based on the GHCA board-review copy and supplied visual reference.

## Project structure

```text
site/
├── public/
│   ├── images/              # Production image assets
│   └── favicon.svg
├── src/
│   ├── components/          # Shared header, footer, forms, icons, and page hero
│   ├── data/                # Reusable site content and structured records
│   ├── pages/               # One React component for each visitor page
│   ├── styles/              # Shared responsive visual system
│   ├── App.jsx              # Routing, page titles, and notifications
│   └── main.jsx             # React entry point
├── .openai/hosting.json     # Hosting configuration
├── index.html               # Vite HTML entry
├── package.json             # Scripts and dependencies
├── vite.config.js           # Production build configuration
└── dist/                    # Generated by `npm run build`; do not edit
```

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Content to confirm before public launch

- Board member names, roles, biographies, and portraits
- Official contact email, phone number, and mailing address
- Approved event dates, times, and locations
- Membership, volunteering, and donation workflows
- Governance, meeting, project, financial, and newsletter files
- Final issue positions, timelines, and public-action links
